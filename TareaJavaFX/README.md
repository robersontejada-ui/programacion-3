## Descripción de las interfaces

### 1. Registro de Visitantes

Esta interfaz fue diseñada para registrar la información de los visitantes de una institución. Contiene campos para ingresar el nombre completo, cédula, teléfono, motivo de la visita, persona a visitar y fecha. También incluye un ComboBox para seleccionar el tipo de visitante, RadioButtons para indicar el documento entregado, botones de Registrar, Limpiar y Cancelar, además de una tabla donde se visualizarían los visitantes registrados.

---

### 2. Sistema de Inventario

Esta interfaz permite registrar la información de productos de un inventario. Incluye campos para el código, nombre del producto, categoría, precio, cantidad y proveedor. También contiene un ComboBox para seleccionar el estado del producto, CheckBoxes para indicar características del producto, botones para Guardar, Editar, Eliminar y Buscar, así como una tabla para mostrar los productos registrados.

---

### 3. Perfil de Estudiante

Esta interfaz fue diseñada para visualizar o registrar la información de un estudiante. Incluye una fotografía simulada mediante un Rectangle, campos para matrícula, nombre, carrera, correo, teléfono y dirección. Además, cuenta con un ComboBox para seleccionar el semestre, un ListView con las materias inscritas, un área de texto para observaciones y botones para Guardar, Actualizar e Imprimir.

---

## Observaciones

Las tres aplicaciones fueron desarrolladas utilizando JavaFX y cumplen con los requisitos establecidos en la asignación. No se implementó lógica de negocio, manejo de eventos, conexión a bases de datos ni almacenamiento de información, ya que el objetivo de la práctica fue únicamente el diseño de las interfaces gráficas.
