## Tarea - Manejo de Excepciones en Java
Descripción

Este programa permite registrar usuarios y validar la información ingresada.

Se utilizan excepciones personalizadas para controlar errores en los datos introducidos por el usuario.

## Datos solicitados
Nombre
Edad
Correo electrónico
Salario mensual
Validaciones
El nombre no puede estar vacío.
El nombre debe tener al menos 3 caracteres.
La edad debe estar entre 18 y 100 años.
El correo debe contener @ y .
El salario debe ser mayor que cero.
Excepciones utilizadas
NombreInvalidoException
EdadInvalidaException
CorreoInvalidoException
SalarioInvalidoException
InputMismatchException
Conceptos aplicados
try
catch
múltiples catch
finally
throw
throws
getMessage()
Cómo compilar

javac *.java
